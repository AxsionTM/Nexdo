# ️ Планирование времени

## Повестка дня

Повестка работает как временная шкала с точностью до минут.

Поддерживается:

- отображение точного времени начала и окончания;
- многочасовые задачи;
- позиционирование по минутам;
- дополнительные отметки `:15`, `:30`, `:45`;
- drag-and-drop задач на нужное время;
- перенос задачи на другой день;
- задачи, пересекающие полночь;
- автоматическое размещение пересекающихся задач рядом друг с другом.

Если две или несколько задач занимают один временной промежуток, они **делят доступную ширину**, поэтому одна задача не перекрывает другую.

### Пересечения расписания

При создании задачи с уже занятым временным интервалом приложение показывает отдельное окно предупреждения.

В предупреждении отображаются:

- конфликтующая задача;
- её описание;
- дата;
- время;
- список пересечений.

Создание при этом не блокируется: пользователь может отменить действие или подтвердить создание задачи на это же время.

# Календарь

Календарь поддерживает два режима:

- **Месяц**
- **Неделя**

Режим **«День»** намеренно убран из календаря: для детального планирования одного дня используется отдельная **Повестка дня**.

Поддерживается:

- отображение задач по датам;
- drag-and-drop между днями;
- перенос даты задачи;
- навигация по неделям и месяцам;
- отображение дней рождения;
- многочасовые и многодневные задачи.

# Obsidian-style граф

Одна из основных функций TaskFlow — интерактивный граф задач в стиле Obsidian.

Граф визуализирует не просто список задач, а **структуру и связи между датами, задачами и подзадачами**.

### Иерархия

Основная структура:

```text
Дата
 ├── Задача
 │    ├── Подзадача
 │    │    └── Подзадача
 │    └── Подзадача
 └── Задача
      └── Подзадача
```

При выборе дня раскрывается вся доступная иерархия этого дня.

При этом подзадача **не подключается напрямую к дате** — она связана только со своей родительской задачей.

### Визуализация

Граф использует:

- force-directed физику;
- динамическое размещение узлов;
- PageRank для визуального веса узлов;
- кластеры;
- цветовое кодирование приоритетов;
- отдельный цвет для подзадач;
- отдельное оформление сегодняшнего дня;
- связи между датами;
- масштабирование колёсиком;
- перемещение графа;
- перетаскивание узлов;
- выделение связанных узлов;
- затемнение несвязанных узлов;
- визуальную иерархию размеров;
- 3D-like визуальное оформление.

### Цвета

Граф визуально разделяет:

- **Сегодня** — отдельный акцентный цвет;
- **Дни** — цветовая последовательность календаря;
- **Приоритет** — цвет задачи зависит от приоритета;
- **Подзадачи** — отдельный фиолетовый оттенок, не конфликтующий с цветами приоритетов;
- **Без приоритета** — тёмно-зелёный.

Выполненные задачи не используются как активные узлы графа.

### Взаимодействие

- Клик по дате — выбрать день и раскрыть иерархию.
- Клик по задаче — открыть подробности задачи в правой панели.
- Перетаскивание — перемещение узлов / навигация по графу.
- Колесо мыши — масштабирование.
- Двойной клик по задаче — открыть её детали.

# Obsidian Vault

TaskFlow поддерживает обмен данными с Obsidian.

Доступны:

- экспорт задач в `.md`;
- экспорт структуры `.obsidian`;
- импорт vault;
- сохранение и восстановление структуры задач;
- перенос иерархии задач и подзадач;
- использование Markdown-представления для данных.

Граф и экспорт построены вокруг идеи:

```text
Дата → Задача → Подзадача
```

чтобы структура TaskFlow могла быть представлена как связанный набор заметок.

# AI

В TaskFlow есть отдельный AI-сервис на Python/FastAPI.

AI используется для работы с задачами:

- анализ задачи;
- предложение приоритета;
- разбиение задачи на шаги;
- подсказки по структуре выполнения;
- массовая расстановка приоритетов.

### AI приоритеты

На странице «Сегодня» доступно общее действие:

**AI приоритеты**

Оно анализирует открытые задачи текущего дня и помогает автоматически расставить им приоритеты вместо ручного открытия каждой задачи.

AI-сервис может работать отдельно, а API содержит fallback-логику для случаев, когда внешний AI-сервис недоступен.

Поддерживается система напоминаний:

- напоминания относительно даты и времени задачи;
- браузерные уведомления;

Также предусмотрена работа с задачами, у которых время уже прошло в текущем дне: приложение может визуально показать, что запланированное время прошло, не превращая такую ситуацию автоматически в потерянную статистическую историю до окончания соответствующего дня.

## Установка

```bash
git clone https://github.com/AxsionTM/TaskFlow.git
cd TaskFlow

npm run install:all
```

Либо вручную:

```bash
cd apps/api
npm install

cd ../web
npm install
```

```bash
cd apps/ai
pip install -r requirements.txt
```

# Последние крупные доработки

В последних версиях были значительно переработаны планирование времени и Obsidian-граф.

### Obsidian

- исправлено отображение подзадач;
- добавлено автоматическое раскрытие иерархии;
- исправлены связи дата → задача → подзадача;
- исключены прямые связи подзадач с датами;
- добавлена отдельная визуализация подзадач;
- улучшена force-directed физика;
- сохранены PageRank и кластеры;
- добавлен переход из узла задачи непосредственно в детали;
- сохранены `.md` / `.obsidian` export/import.

### Планирование

- исправлена обработка задач с точным временем;
- исправлены overnight-задачи;
- улучшена логика просроченных задач;
- добавлено позиционирование по минутам;
- исправлено перекрытие нескольких задач;
- задачи в одном временном диапазоне теперь распределяются по ширине;
- добавлено предупреждение о пересечении времени без запрета создания.

### Задачи и подзадачи

- исправлено дублирование подзадач;
- улучшено выполнение подзадач через checkbox;
- удаление подзадачи вынесено в отдельное действие;
- добавлен подробный task drawer;
- отображаются сроки, проект, статус, родительская задача и прогресс подзадач.

### Inbox / Calendar

- просроченные задачи предыдущих дней не смешиваются с актуальными Inbox-задачами;
- Inbox группируется по датам;
- календарь оставлен в режимах «Месяц» и «Неделя»;
- отдельный режим «День» заменён полноценной «Повесткой дня».
