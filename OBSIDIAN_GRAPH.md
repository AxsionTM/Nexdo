# Obsidian-style graph

В TaskFlow добавлен интерактивный граф связей, вдохновлённый Graph view из Obsidian.

## Что отображается

- **Задачи** — узлы задач.
- **Проекты** — узлы проектов; задача соединяется со своим проектом.
- **Теги** — узлы тегов; задача соединяется со всеми своими тегами.
- **Подзадачи** — отдельная связь между родителем и ребёнком.

## Физика и управление

- force-directed layout: притяжение связанных узлов, отталкивание соседних узлов, гравитация к центру и демпфирование;
- пространственное хеширование для локального расчёта отталкивания и стабильной работы на больших графах;
- перетаскивание узлов;
- панорамирование пустого пространства;
- zoom колесом мыши и кнопками;
- fit/reset;
- пауза/запуск физики;
- подсветка соседей выбранного узла;
- поиск и фильтрация по типам узлов;
- двойной клик/кнопка «Открыть задачу» открывает существующую карточку задачи.

## API

Добавлен авторизованный endpoint `GET /graph` с параметрами:

- `includeCompleted=true|false`;
- `limit=1..2000`.

Endpoint строит граф только из данных текущего пользователя и не требует изменений Prisma schema.
